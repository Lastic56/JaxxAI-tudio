Important: selecting a GGUF file is not the same as running it. This web app currently uses Transformers.js for ONNX models; GGUF requires a compatible llama.cpp/WebAssembly runtime, which is not yet bundled in this build. The file is not uploaded or sent anywhere.
For best results, use a quantized GGUF model sized for your available RAM. Large files can use several times their file size in working memory.

Model library

Choose a compact model by task and estimated download size. Download sizes are approximate and depend on the model files and quantization served by the repository.

Use a public repository compatible with Transformers.js text-generation and containing browser-ready ONNX weights. Large or unsupported repositories may fail.

Runtime settings

Adjust how the model runs in this browser.

WebGPU support depends on your browser and graphics hardware. If it fails, switch back to WASM.

Model weights are large binary files, so this app uses the browser's persistent cache rather than localStorage (which is too small for model weights). Browser storage can be cleared by your browser or operating system.
